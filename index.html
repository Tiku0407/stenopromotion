Retirement Timeline

नियम: सेवानिवृत्ति आयु 62 वर्ष। यदि जन्मतिथि महीने की 1 तारीख है → retirement पिछले महीने के अंतिम दिन; अन्यथा → उसी महीने के अंतिम दिन।

पद पूर्ति Projection — सभी संवर्ग

प्रत्येक संवर्ग की पदक्रम सूची (वरिष्ठता क्रमांक) के अनुसार अगले संवर्ग में पदोन्नति की पात्रता स्थिति। निर्धारित अर्हता: SSO → PSO व SO → SSO हेतु 03 वर्ष; निज सचिव → SO, निज सहायक → निज सचिव, शीघ्रलेखक → निज सहायक, स्टेनो टाइपिस्ट → शीघ्रलेखक हेतु 05 वर्ष सेवा अवधि। PSO (Level 15, 37400–67000 + GP 8700) के 03 स्वीकृत पद हैं — SSO seniority से भरे जाएँगे।

Promotion Chain Projection (Year-by-Year)

Logic: प्रत्येक वर्ष के retirements + मौजूदा रिक्तियों से ऊपर के संवर्ग में पद खाली होते हैं → नीचे के संवर्ग से सबसे senior पात्र officer promote होता है → उसकी जगह और नीचे से भरती है।
निर्धारित अर्हता (सेवा अवधि): SSO → PSO : 03 वर्ष SO → SSO : 03 वर्ष निज सचिव → SO : 05 वर्ष निज सहायक → निज सचिव : 05 वर्ष शीघ्रलेखक → निज सहायक : 05 वर्ष स्टेनो टाइपिस्ट → शीघ्रलेखक : 05 वर्ष
Chain क्रम: स्टेनो टाइपिस्ट → शीघ्रलेखक → निज सहायक → निज सचिव → स्टॉफ ऑफिसर → वरिष्ठ स्टॉफ ऑफिसर → PSO (2029 से)
यह seniority-आधारित indicative projection है — वास्तविक पदोन्नति DPC, ACR/APAR, roster एवं विभागीय नियमों पर निर्भर करेगी।
